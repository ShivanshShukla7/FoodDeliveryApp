# Food Delivery Application

## Description

A simple Food Delivery Application developed as part of Agile Assignment.

## Features

- View food menu
- Add food to cart
- Calculate total price
- Simple user interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Agile Methodology

The project is managed using Jira and Kanban.

## Version Control

Git and GitHub are used for source-code management.
